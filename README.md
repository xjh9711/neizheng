## 本书讲什么

- **作者自述**：以内证（修道人以内观方式观察自身与宇宙）记录中医解剖学——观察对象是"无物质"（真气、光、阴阳、五行等肉眼与仪器看不到的物质）。
- **主体内容**：2007 年前后的逐时辰内证观察记录，配"真图"。
- **全书结构**：上编 内证漫谈（7卷）· 中编 神奇的太极器官与五藏（7卷）· 下编 十二正经观察（13卷）· 后记与附录（刘力红序、《问道》访谈、中医的十个秘密、编辑手记等）。
